# Public Pocket sample photographs

These photographs have explicit reuse licenses; being publicly viewable alone
would not be enough. They are third-party sample stills, not OsmoDesk test footage,
not DJI-provided promotional assets, and not evidence of Pocket 3 compatibility.
Sources and license statements were checked on 2026-09-15.

- Source title: *Couchée du soleil sur le fleuve le Niger à Kourala*
- Creator: **AConde11**
- [Source and attribution page](https://commons.wikimedia.org/wiki/File:Couch%C3%A9e_du_soleil_sur_le_fleuve_le_Niger_%C3%A0_Kourala.jpg)
- License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- Original dimensions: 3492 × 1964.

The downloaded JPEG is unchanged. In the desktop and mobile demo captures it is
scaled to the monitor viewport. In `osmodesk-cinema-workspace-illustration.png`
it is further perspective-transformed and AI-rendered as part of an illustrated
laptop screen. Those adaptations must retain this source, credit, license link
and change notice when shared. The embedded photo remains under CC BY 4.0;
this notice does not apply that license to OsmoDesk source code or unrelated art.

Suggested credit when sharing the illustration or a sunset screenshot:

> Demo photo: AConde11, “Couchée du soleil sur le fleuve le Niger à Kourala”,
> CC BY 4.0, via Wikimedia Commons. Scaled for the demo; perspective-transformed
> and AI-rendered in the setup illustration. Source and license links above.

## Camera attribution and limits

Both source pages expose DJI / PP-101 camera metadata and appear in Wikimedia
Commons' Pocket 3 photographs. DJI identifies PP-101 as Osmo Pocket 3 in its
[official safety guidelines](https://dl.djicdn.com/downloads/DJI_Osmo_Pocket_3/SG/20241226/DJI_Osmo_Pocket_3_Safety_Guidelines_5_lan_v1.0_%28Creator_Combo%29.pdf).
This is source/metadata attribution, not an independent authentication of the
capture process. Neither photographer nor DJI endorses OsmoDesk.

The [official DJI Pocket 3 sample gallery](https://store.dji.com/ph/content/vlog-sample-footage-of-pocket-3?set_region=PH)
is another viewing reference, but its images have **not** been copied here:
we did not establish a redistribution license for those assets.
