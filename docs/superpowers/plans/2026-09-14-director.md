# Director Implementation Plan

**Goal:** A camera-off rehearsal and timing-proposal workflow with safe shared authoring and trustworthy take evidence.

**Architecture:** Keep `Move.sample`, `Move.retimed`, `preflight.check`, the existing runner and workspace journal canonical. Add a pure Director service and a focused browser module. Requests to preview never arm, acquire motion, or reach camera transport.

**Tech Stack:** Existing Python standard-library host and vanilla HTML/CSS/JS; existing unittest and offline Playwright harness. No new framework or package installation.

**Spec:** `docs/DIRECTOR-RESEARCH.md`.

## Global constraints

- Preserve the existing uncommitted Shot Studio changes and measured camera coordinate conventions.
- No commits, pushes, deployment, camera connection, firmware, or hardware actions.
- Root owns `server.py` and browser integration; each worker has exclusive explicitly named files.
- Work in the existing isolated `codex/cinema-workspace` checkout.
- New behavior uses failing regression tests first. Keep old meaningful guards.
- Preview/fit is arithmetic only; actual execution retains explicit controls and universal STOP.

## Implementation

- [x] Motion foundation: immediate-neutral telemetry/target faults, no stale trace and finite non-loop round trips; focused runner/move regressions.
- [x] Take evidence: bounded finite ordered input, coverage/gap/aborted labels; root integration of saved full-duration context and stable take IDs.
- [x] Director service: canonical sampled preview, beats and checked `Move.retimed` proposals; short-leg peaks, long dwells, timing floors, round trips and assessment bounds tested.
- [x] Shared host contract: same-origin JSON writes, generation conflicts, durable-save truth, per-tab ordered motion leases, held-gesture STOP and expired/refused-clutch guards.
- [x] Director UI: camera-free preview, cue holds, beat selection, timing preview/apply/restore, reduced-motion cursor and focused waypoint editing. Failed/stale responses and newer same-tab edits are guarded.
- [x] Integrated gate: 1,175 offline tests passed with no skips; actual Chrome/HTTP integration passed at three widths across five workspaces. Final captures inspected; independent cold review findings repaired and reviewed.
